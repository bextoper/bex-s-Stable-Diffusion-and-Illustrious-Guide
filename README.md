# bex's Stable Diffusion and Illustrious Guide

A guide to Stable Diffusion and Illustrious-based models: installing ForgeUI and ComfyUI, prompting basics, and advanced techniques.

The guide is written in Markdown under [`docs/`](docs/) and built with [MkDocs](https://www.mkdocs.org/) and hosted on GitHub Pages.

## Building locally

```bash
pip install -r docs/requirements.txt
mkdocs serve
```

## Deploying

Pushing to `latest` rebuilds and publishes the site to GitHub Pages automatically (see `.github/workflows/deploy.yml`). You can also run it by hand from the Actions tab.

Questions, advice or corrections: `@bextoper` on Discord.
